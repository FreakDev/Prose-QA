# Goal

Navigate across the demo site using the main navigation links.

# Steps

1. Confirm the home page has loaded with **Hello World**.
2. Click **Form playground** in the main navigation.
3. Confirm the form playground page has loaded.
4. Click **Home** in the main navigation.
5. Confirm the home page is visible again.
6. Click **Sign in** in the main navigation.
7. Confirm the sign-in page has loaded.

# Then

- url contains "/login"
- page shows "Sign in"
